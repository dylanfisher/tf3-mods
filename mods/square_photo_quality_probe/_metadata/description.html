DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for a planned photo mode mod and does nothing useful for players.

A top-bar button switches the graphics settings to a boosted preset (Very High, max anti-aliasing, 100 % resolution scale) and back, without saving them. Load settings change the camera tool, camera tool preview and High geometry tiers (draw distance, LOD scaling). A second button opens a test window for photo mode features (screenshots, hiding the UI, time of day, pause, environment, cutscene camera, atmosphere fields, bloom / HDR settings keys, shader override check). It writes [SQPQ] lines to stdout.txt. Tests put back what they change; saving while a time of day, pause or environment test is active can keep that change in the save.
