DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for the planned "Balance vehicles" feature of Line Manager Plus and does nothing useful for players.

It mounts an "LMPP" test button left of A+ in the Line Manager line toolbar and writes [LMPProbe] lines to stdout.txt. Snap only reads. The Send buttons re-send one line vehicle to a stop of its own line (an ordinary vanilla command; removing the mod leaves nothing behind), so use a test save.
