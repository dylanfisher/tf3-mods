Find the town buildings your supply routes don't reach. Switch the gaps on and every town building that needs a cargo but isn't getting it gets a marker, so you can see exactly where a new truck stop would close the gap.

Click the Supply Gaps button (a house icon) in the top-left button ridge to open the panel, tick Show supply gaps and pick a cargo. The markers stay up while you place stops: put a stop on a line and the buildings it reaches lose their markers within about a second.

Features

  • Yellow arrow markers on town buildings that no stop delivering the cargo reaches.
  • Red question-mark markers on buildings that a delivering stop reaches, but whose stock of the cargo has been empty for about 20 seconds.
  • Cargo picker with icons: All needed, or one cargo. Each row counts the buildings not reached, in range but empty, and all buildings that need it.
  • Area labels under each town name: the share of each district's buildings that get the cargo, as a percentage per district. They also show in the Cargo Flow layer.
  • Follows the camera: only the towns on screen are counted and marked, and the panel names them. Pan to another town and it updates.
  • Built to be light: it works once a second, only for the towns on screen, skips work when nothing changed, and spreads its reads over several seconds. While the markers are off it does no work.
  • Preview a stop: Count stops without a line treats a new cargo stop as delivering before it is on a line.
  • Remembered per save: a game saved with the markers on loads with them on; every other game starts with them off.

Options (in the panel)

  • Show supply gaps (default Off, saved with the game): the markers and labels.
  • Only towns in view (default On): count and mark only the towns on screen. Untick for the whole map.
  • Include in-range but empty (default On): also mark buildings in range whose stock stays empty.
  • Area labels (default On): the district rows under town names.
  • Count stops without a line (default Off): treat cargo stops that no line serves yet as delivering, to preview a new stop's coverage.

Settings

  • Top bar button (default Icon): the button that opens the panel. Icon: a house icon on a dark tile, like the game's data layers button; it gets a green border while the markers are shown. Text: the word "Gaps".
  • Debug: performance log (default Off): writes timing lines to the game's log file every 30 s. Only for tracking down slowdowns.

Notes

  • A stop added to or removed from a line shows on the next update, about a second. Other line changes, such as which cargo a line loads, can take up to about 10 seconds.
  • At most 300 markers are shown, the ones nearest the centre of the screen.
  • The options other than Show supply gaps last for the session; every game starts with their defaults.
  • Reads the game state only and changes nothing in the simulation. The mod is cosmetic and keeps achievements enabled. It stores one on/off flag in the savegame: it can be added to existing saves, and removing it from a save shows the game's standard warning.

Revision 5 (2026-10-12)

  • The game's data layer windows (Infrastructure, Traffic and the others) now open below the top-left button row instead of under its buttons.
  • New: mod setting "Top bar button": the button that opens the panel is now a house icon on a dark tile that stays pressed while it is open, like the game's data layers button, with a green border while the markers are shown (default), or the word "Gaps" as before.
  • Fixed for PlayStation 5: the Supply Gap Overview window no longer crashes the UI when it opens. A window option the platform doesn't support (such as the close button) is left out instead.

Revision 4 (2026-10-10)

  • Changed: in-range-but-empty buildings now get a red question mark instead of a yellow exclamation mark, so they stand apart from the yellow arrows at a glance. The options now sit above the cargo list, so they no longer move when the list changes.
  • Faster: ticking an option or picking a cargo now updates the panel and the markers straight away, instead of after up to a second.
  • Fixed: fewer stylesheet rules (26 → 18), so large mod sets no longer hit the game's load crash (the game crashes on load when mods add too many style rules).
