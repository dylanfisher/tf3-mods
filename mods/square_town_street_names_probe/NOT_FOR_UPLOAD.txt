DEV ONLY - NOT FOR UPLOAD

square_town_street_names_probe is a developer tool for the planned square_town_street_names mod. Never
publish it to mod.io (Mod Hub > My Mods would offer it because `make link` puts it in the staging area).

It logs [SQTSN_PROBE] lines to stdout.txt: towns, which entities carry names, and every newly built street
stop / station (ids, names, town, detection hook). Read-only unless the "Rename test (DEV)" mod param is
switched on. It also adds a name set "DEV TSN Probe" that logs every call of the street/town name scripts;
pick it only in a throwaway new game. How to run it: plans/square_town_street_names/PROBE.md.

When done testing: disable it in the game's mod list, or `rm` its symlink from staging_area
(make unlink removes every mod's link).
