DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for a planned town street names mod and does nothing useful for players.

It writes [SQTSN_PROBE] lines to stdout.txt: the towns, which entities carry names, and every newly built street stop or station with its names, town and the hook that detected it. It is read-only unless the "Rename test (DEV)" param is switched on. It also adds a name set, "DEV TSN Probe", that logs every call of the street and town name scripts.

Notes

  • Steps: plans/square_town_street_names/PROBE.md in the mod hub repository.
  • Only pick the "DEV TSN Probe" name set in a throwaway game.
