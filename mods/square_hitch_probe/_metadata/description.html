DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool and does nothing useful for players.

A small button in the top-left mod area cycles fake pauses: the game script (or, as a control, the interface) busy-waits for a set time about every 2 seconds. Every frame time is written to stdout.txt as [HITCH] lines, so a report can tell whether a game-script pause shows up as a slow frame.

Notes

  • Steps: plans/hitch_probe/README.md in the mod hub repository.
  • Use a copy of a save. The probe keeps its pause setting in the save.
