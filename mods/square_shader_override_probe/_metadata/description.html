DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer test for a planned photo mode mod and does nothing useful for players.

It replaces the game's HDR compose shader with a copy that tints the whole 3D view magenta, to find out whether a mod can override a base shader file (at load, or after AltGr+R in debug mode). Enable it only for that test.
