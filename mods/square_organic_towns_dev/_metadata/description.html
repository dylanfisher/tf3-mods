DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool and does nothing useful for players.

An "OT Dev" button in the top-left mod area opens a window with test tools for Organic Towns (square_organic_towns, which must be enabled): a town inspector, Grow now (next increments plus forced growth), growth in any of the nine city types, a fast-forward of all towns, a dry run with markers, undo of the last increment, pause / debug log switches for the main mod's driver, and Simulate natural growth (towns grow as if connected, on any map without transport, through the game's own size command). Every step is one [SQOT_DEV] line in stdout.txt.

Notes

  • Steps: plans/square_organic_towns/TESTING.md "Dev tools" in the mod hub repository.
  • It builds and removes streets and grows towns for good: use a throwaway save and keep backup saves.
