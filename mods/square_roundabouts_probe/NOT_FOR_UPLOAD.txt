DEV ONLY - NOT FOR UPLOAD

square_roundabouts_probe is a developer tool for square_roundabouts. Never publish it to mod.io
(Mod Hub > My Mods would offer it because `make link` puts it in the staging area).

It asks the engine (api.engine.util.proposal.makeProposalData) which construction param
combinations cannot be placed and logs [SQRB_PROBE] lines to stdout.txt. It never builds
anything. How to run it: plans/square_roundabouts/PROBE.md. Parser: tools/parse_probe.py.

When done testing: disable it in the game's mod list, or `rm` its symlink from staging_area
(make unlink removes every mod's link).
