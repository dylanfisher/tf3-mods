DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for Better Roundabouts (square_roundabouts) and does nothing useful for players.

On game load it asks the engine whether each combination of Better Roundabouts settings could be placed, without building anything, and writes one [SQRB_PROBE] line per combination to stdout.txt. tools/parse_probe.py turns the log into a report.

Features

  • Placement probe: builds a construction proposal per combination and reads the engine's error messages from makeProposalData. Never sends a build command.
  • Effective size: logs the radius (or Magic size) the roundabout geometry chose, to compare with the engine verdict.
  • Search subsets: per combination, asks about exact layouts (ring radius, Magic size and spacing, splitter parameters, tram stub) through dev-only construction params, and finds the smallest or most compact one the engine accepts.
  • Phase 5e subsets: sweeps and searches for the Channelized Junction, the Roundabout Interchange and hamburger roundabouts (p5_*).
  • Dev construction "DEV Probe: pre-1940 one-way": base entrance one-way edges as freed streets, for a pre-1940 save. Places real roads: use a throwaway save.

Settings

  • Run the probe (default On), Subset (default smoke), Start delay (default 15 s), Combos per update (default 4).
  • Position X (m) and Position Y (m) (default 0, the map centre), Proposal context (default None), Log placeable combos (default On).

Notes

  • Use it on an empty, flat test map only. The probe stores nothing in the savegame (the dev construction does, once placed).
  • Steps: plans/square_roundabouts/PROBE.md in the mod hub repository.
