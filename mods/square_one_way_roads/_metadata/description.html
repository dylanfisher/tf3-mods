Horse-drawn carts could manage "this way only" long before 1940. Now your cobblestones can too.

Build one-way roads from the first year of the game. The base game only has one-way versions of the modern town streets, from 1940. This mod adds a one-way version of every other basic road, and each one unlocks and retires together with its two-way version. No road becomes available earlier than it would without the mod.

Features

  • Old town streets: one-way extra small, small, medium and large, until 1940.
  • Modern large street: the one large town street the base game has no one-way version of, from 1940.
  • Country roads: one-way small, medium and large, old (until 1940) and modern (from 1940).
  • Same width, speed and look as the two-way road, with a one-way arrow on the menu icon like the base game's one-way streets. Like the base game's one-way roads they cost about a third less to build and maintain.
  • Towns never build them, so only the roads you choose become one-way.

How to use

  • Pick a one-way road from the road menu, next to its two-way version, and drag it. Traffic runs in the direction you drag.
  • To make an existing road one-way, build the one-way type over it. To turn it round, build it again in the other direction.

Notes

  • Safe to add to an existing save. Removing it also keeps the save loading, but check the roads it added afterwards: they no longer have their one-way type.
