The small coloured line dots above stations and stops on the map are bigger, so they are easier to see and click.

Features

  • Bigger dots: 12 px instead of 7 px.

Notes

  • Only the map interface changes. The mod is cosmetic, keeps achievements enabled and can be added to or removed from any save.
