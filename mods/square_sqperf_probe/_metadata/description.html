DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for the SQPERF performance logging in square mods and does nothing useful for players.

It creates and reads the engine's precise clock in a HUD icon script and in the interface's per-frame callbacks, and writes [SQPERF-PROBE] lines to stdout.txt. It changes nothing in the game.
