See how much every industry produces, how much your lines pick up, and how much cargo flows in and out of every warehouse, at a glance, straight from the map. No more clicking into each industry, warehouse and line window to check the numbers, so you can size and set up your lines much faster.

The mod adds two pills under the output stock of every industry's in-world label, and the incoming and outgoing cargo per year under every warehouse's stock.

Features

  • Production (industry icon): the industry window's headline number, "Current Production" where the window shows it, otherwise the production capacity (raw producers such as mines and fishing grounds). The same game function as the industry window computes it, so it always matches, boosts included. The pill is green while the output is producing and dark while it is idle. Unused industries (every number 0 and no line picking up) show no pills.
  • Line pickup rate (Line Manager icon): the summed "Rate" (from the line window) of all your lines that load this industry's output at a station in reach. Compare it with the production number to see whether your lines can carry everything away. It only appears where such a line exists.
  • One pill per output cargo, with the cargo icon when an industry has several outputs.
  • Warehouse rates: under each warehouse's stock, one row of incoming pills (box with a down arrow, blue) and one row of outgoing pills (box with an up arrow, red), each with the cargo icon and the count per year. These are the same numbers as the warehouse window's Incoming and Outgoing statistics, split by cargo. Only cargos that moved in the last year are shown, busiest first, up to six.

Settings

  • Show production (default On): the production pill.
  • Show line pickup rate (default On): the pickup pill. When it's off, the mod doesn't read your lines at all.
  • Show warehouse rates (default On): the incoming and outgoing pills on warehouses. When it's off, warehouse labels stay vanilla.

Settings can be changed whenever you start or load a game.

Notes

  • Lines that carry several cargos count their full rate for each of them.
  • Production and warehouse rates refresh every two seconds, the pickup rate about every 15 seconds while the game runs. All pills hide when zoomed far out, like the stock numbers.
  • Reads the game state only: it changes nothing in the simulation, stores nothing in the savegame, and can be added to or removed from existing saves.
  • Industries and warehouses from other mods that already set their own label script are left untouched.

Changelog

Revision 7 (2026-10-17)

  • Changed: unused industries (production 0 for every output and no line picking up) no longer show pills, so idle factories keep a clean label.

Revision 6 (2026-10-10)

  • Fixed: fewer stylesheet rules (17 → 7), so large mod sets no longer hit the game's load crash (the game crashes on load when mods add too many style rules).

Revision 5 (2026-10-10)

  • New: translations into Russian, German, French, Spanish, Italian, Dutch, Polish, Portuguese (Brazil), Japanese, Korean and Chinese (Simplified and Traditional). The mod follows the game's language setting.

Revision 4 (2026-10-08)

  • Performance: the line pickup rates are recalculated faster on maps with busy town stations.

Revision 3 (2026-10-07)

  • New: warehouse labels show the incoming and outgoing cargo per year, one pill pair per cargo.
  • New: setting "Show warehouse rates" (default On) to switch the warehouse pills off.
  • Fixed: changing the settings now takes effect when the game is loaded.

Revision 2 (2026-10-07)

  • New: line pickup rate pill under the production number, showing the combined Rate of the lines that pick up the industry's output, including at fishing grounds and other industries with built-in stations.
  • New: both pills can be switched off in the mod settings ("Show production", "Show line pickup rate").
