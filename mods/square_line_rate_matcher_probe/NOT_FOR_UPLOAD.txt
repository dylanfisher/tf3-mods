DEV ONLY - NOT FOR UPLOAD

square_line_rate_matcher_probe is a developer tool for the planned square_line_rate_matcher mod. Never publish it
to mod.io (Mod Hub > My Mods would offer it because `make link` puts it in the staging area).

It mounts an "RM" test button left of A+ in the Line Manager line toolbar and logs [RMPROBE] lines to stdout.txt.
Unlike other probes it DOES change the game: "+1" buys a clone of a line vehicle, "-1" sends the newest line
vehicle to its depot to be sold. Use a test save. How to run it: plans/square_line_rate_matcher/PROBE.md.

When done testing: disable it in the game's mod list, or `rm` its symlink from staging_area
(make unlink removes every mod's link).
