DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for Better Roundabouts (square_roundabouts) and does nothing useful for players.

Warning: the defaults BUILD. With Run On and Mode Build (the defaults), 5 s after a game loads it builds hundreds to thousands of constructions around the map centre. Only enable it on a throwaway Blank Slate map; choose Dry run to only log the plan.

When Run is On, on game load it enumerates Better Roundabouts settings combinations, lays them out across the map in a pattern and writes the plan and an ASCII preview as [SQRB-SHOW] lines to stdout.txt. In Build mode it also builds every combination the engine accepts.

Features

  • Generic combinations: the params come from each construction's own definition, so new settings are picked up automatically. Showcase, every combination (capped), one setting at a time, or a seeded random sample.
  • Patterns: grid, mosaic (quilt by island / lanes), kaleidoscope (4- and 8-fold, with true mirror images from the traffic side), mandala, golden-angle spiral, size gradient, checkerboard, random scatter.
  • Tight packing: exact box collisions, footprints from each road's own width, nearest-free-spot placement; the kaleidoscope keeps exact symmetry.
  • Safe building: one build at a time, each checked with makeProposalData after the previous one is built; refused ones, collisions and spots off the map or on water move to the nearest free spot up to twice, then are skipped and logged, never forced. Nothing is bulldozed.
  • Dry run (default): only logs the layout.

Settings

  • Run (default On), Mode (default Build), Start delay (default 5 s), In flight (default 16 builds at once; neighbours within 50 m still wait for each other).
  • Constructions, Combinations, Cap (default 2000 constructions), Fill (default Repeat: combinations are placed again until the cap or the max radius is reached), Pattern, Gap (default 10 m), Rotation, Position (default X / Y = 0 / 0, the map centre; or the camera centre), Max radius, Seed.

Notes

  • Use it on an empty, flat test map only. The script stores nothing in the savegame; the constructions it builds are ordinary Better Roundabouts roads.
  • Steps: plans/square_roundabouts_showcase/PLAN.md in the mod hub repository.

Changelog

Revision 1 (dev, never uploaded)

  • New: combination enumeration from the construction params, nine layout patterns, dry run with ASCII preview, checked batch building.
  • Tight packing (fill % logged), road-width margins, gaps from 0 m (default 10 m), building with retries.
  • Road-shape collisions: pieces interlock and sit in the empty corners of bigger ones; refusals log which build they hit.
  • Faster building: up to 16 spatially independent builds in flight. Fill: repeats until the cap or the max radius. Defaults now build at the map centre 5 s after loading.
