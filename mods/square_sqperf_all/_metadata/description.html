DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for the SQPERF performance logging in square mods and does nothing useful for players.

While it is enabled, every square mod with SQPERF writes its performance log to stdout.txt as if its own "Debug: performance log" setting were On: 30 s summaries per instrument plus the debug-gated lines. It has no scripts and no settings, and changes nothing in the game.

Notes

  • How it works: plans/sqperf/README.md "Master switch" in the mod hub repository.
