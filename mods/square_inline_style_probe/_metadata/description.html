DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer probe and does nothing useful for players.

From the first frame after loading a game it renders 60 invisible components in the main mod button area, each with its own distinct inline StyleSheet. It has no stylesheet (.css.lua) and no game script. Purpose: find out whether inline styles count toward the game's load crash above ~200 mod stylesheet rules.
