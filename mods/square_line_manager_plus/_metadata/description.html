Get to any line faster and see how it is doing without opening it. Shift-click a line on the map to open it straight in the line manager, and hover any line (in the line manager's list, on the map while the line manager is open, or in the Send to Line list and on the map while sending) for an instant info box with its vehicles, Capacity, Utilization, Frequency and Rate. While you send vehicles, the box also shows what sending them would change.

The line manager's vehicle list also shows what each vehicle carries right now, so you can spot the empty ones at a glance, gives vehicle names a wider column so more of a long name fits, and hovering a vehicle's picture shows its line, parts (every locomotive and wagon of a train), speed, condition and costs. On top of that: a Line actions menu with Match line rate (size a line's fleet to the cargo it serves), Duplicate line, Reverse line and Duplicate + reverse line, and Undo and Redo buttons for editing a line's stops. Each feature can be switched off on its own in the mod settings.

Replaces Line Editor Undo. Line Manager Plus includes everything Line Editor Undo does. If you use Line Editor Undo, disable it and enable Line Manager Plus instead. The game warns you when both are enabled; if you keep both anyway, only one set of undo buttons appears.

Map: Shift-click a line

  • Shift-click one of your lines on the map to open the line manager on it, without the line window first. A plain click still opens the line window.
  • With a line window open, Shift-click empty ground or water to open the line manager on that line (the line drawn by the window can't be clicked itself, so a click on it lands on the ground below).
  • Works on the plain map and with entity windows open. Vehicles, stations and other companies' lines open their usual window; builders and the line manager keep Shift for themselves.

Line list: line info on hover

  • Hover a line in the line manager's line list, anywhere on its row: an info box right outside the line manager (left of it when the window is on the right of the screen), level with the row, shows the line's name, vehicles by model and its Capacity, Utilization, Frequency and Rate, the same details and look as in the Send to Line list. It appears at once, with no tooltip delay, and goes when the mouse leaves the row.
  • The list itself works exactly as before: selecting, the checkboxes, the rename, locate and delete buttons, scrolling, search and the game's tooltips. Depot rows show no info box.

Line details: average utilization

  • In the statistics row at the bottom of the line manager, the Utilization of the selected line now also shows its average over the last 12 game months in light blue, e.g. "100% avg 87%". It is sampled four times a game month while you play and starts anew each time you load a game ("avg ~87%" until 12 months are covered; its tooltip says how many so far). Nothing goes into your save. This one has no setting: it always applies.

Vehicle list: current cargo and longer names

  • Every vehicle in the line manager's vehicle list shows its current load between its name and its picture: the cargo's icon and how full it is, e.g. "6/25". An empty vehicle shows a greyed "0/25", so you can see at once which trucks run empty, or pick the empty one when you take vehicles off a line.
  • The numbers are for the whole vehicle. A vehicle with several cargo types aboard, like a mixed train or a ship, shows up to three cargo icons, fullest first, and "+1", "+2" for any more; the column only takes room for as many icons as the line's vehicles can carry. Hover the load to see every type with its own load, and any space not yet given to a cargo. Updates every second.
  • The load is part of the row and lights up with it. Renaming works as before (the pen sits between the name and the load).
  • The picture column is only as wide as the widest picture in the list, and the name column takes the rest: on bus, truck and plane lines long vehicle names show almost in full, while train lines keep room for their pictures (cut off at the right beyond about 120 px). This one has no setting: it always applies.

Vehicle list: vehicle info on hover

  • Hover a vehicle's picture in the line manager's vehicle list to see a box next to the line manager with the vehicle's name, its line (or In Depot / Going to Depot) and its parts: every locomotive and wagon of a train, e.g. "Big Boy, Tender, 12× Boxcar".
  • Below that: top speed (of its slowest part), power, weight, age, condition, running costs per year, current value and last year's balance.

Buy Vehicles: filtered by the line's cargo

  • Click Buy Vehicles for a selected line and the vehicle store opens with the line's cargo already ticked in its cargo filter: passengers for a bus line, coal for a coal line. Untick it to see everything, as usual. For trains, it applies on the wagon and multiple unit tabs.
  • Replace (and Modify) for vehicles of one line, from the Line Manager or a vehicle's window, opens the store with that line's cargo ticked too.
  • The cargo is what the line's stops are set to load, so a new line without vehicles works too.
  • Only for lines that carry one cargo type (the store's filter shows only vehicles that carry every ticked type, so a passenger and mail line opens unfiltered).

Map: line info on hover

  • With the line manager open, hover one of your lines on the map: below the game's "Select Bus Line 1." text you see the line's vehicles by model and its Capacity, Utilization, Frequency and Rate, the same details as in Send to Line (without the before → after estimate, since nothing is being sent).
  • Clicking the line still selects it as before. Stations, depots and the other hover texts are unchanged.

Send to Line: target line info

  • Select vehicles in the line manager, click Send to Line and hover a line on the map: below the game's "Send 3 vehicles to Bus Line 1." text you see the line's vehicles, grouped by model ("3× Foo", "1× Bar", the largest groups first), or "No vehicles on this line."
  • The line's Capacity, Utilization, Frequency and Rate, worked out with the same game functions as the statistics row at the bottom of the line manager, so the numbers match.
  • Before → after estimate: the same text also shows what sending the selected vehicles would do, e.g. "Capacity: 40 → ~80", "Frequency: 7 min 19 s → ~4 min 53 s", "Rate: 66 → ~132". Frequency assumes the new vehicles are about as fast as the line's; rate grows with the added capacity. The "~" marks an estimate, and Utilization stays the current value (it depends on demand the game can't predict). Vehicles already on that line don't count; if some selected vehicles can't carry the line's cargo, a line says how many.
  • In the Send to Line list too: hover a line in the list that the Send to Line button opens, and an info box appears outside the popup, right next to it (left of it when the popup is on the right of the screen), with the line's name, vehicles by model and Capacity, Utilization, Frequency and Rate, and the same before → after estimate. The list itself works exactly as before.
  • Follows "Show Only Visible Lines": when the line manager's line list shows only visible lines (the eye button in its filter bar), the Send to Line list opens filtered the same way. The line manager now remembers that eye button with your savegame: it is kept when you save and comes back when you load that game (a new game starts with it off). Clicking the eye inside the Send to Line list still applies to that list only.
  • Works for passenger and cargo lines of every transport type.

Line actions: Duplicate and Reverse line

  • A Line actions button (a list icon) right of the Auto-Rename button of a single selected line opens a small menu in the style of the game's Auto-Rename menu: Match line rate (below), Duplicate line, Reverse line and Duplicate + reverse line.
  • Duplicate line makes a new line with the same stops and every stop setting (terminals, waypoints, load mode, waiting times, cargo settings), named "Bus Line 1 (copy)" ("(copy 2)" and so on if that name is taken), with a new color picked the way the game picks one for a new line. It starts without vehicles: send some with Send to Line or buy new ones. The line manager then switches to the copy.
  • Reverse line serves the stops in the opposite order. Stop 1 stays first, waypoints follow their stretch of the route, and terminals are chosen anew for the new direction (for example the bus stop on the other side of the street). The vehicles stay on the line. With the Undo button on, one Undo takes the reverse back.
  • Duplicate + reverse line makes the copy already reversed: a new line for the opposite direction, with a new color and no vehicles, while the original line stays as it is.
  • Greyed out, with the reason in the tooltip, for a line with fewer than 2 stops or a demolished station. Reverse line and Duplicate + reverse line need at least 3 stops: a line with 2 already runs both ways. If the game refuses the change, a message says so and the line stays as it was.

Line actions: Match line rate

A logging camp makes 101 logs a year and your ship line moves 66 with 2 ships? Match line rate shows that 3 ships reach about 99 and 4 about 132, what each option costs, and whether another ship model would carry the logs for less. Nothing is bought or sold until you press Apply.

  • Match line rate, first in the Line actions menu (needs the Line actions button), opens a window titled with the line's name. Check the target, pick a row in the options table or a model in the comparison, and press Apply. Clicking it again brings the window to the front.
  • Line stats: Rate, vehicles, Rate per vehicle and running costs per year, the same numbers the line manager and the vehicle windows show.
  • Supply: for each cargo the line loads, what the producers in reach of its loading stops can make per year, what they actually produced and how much other lines already take there. The target follows the cargo that needs the most vehicles.
  • Target: suggested from the supply, or type your own Rate per year, with - and + buttons and a Suggested button to go back.
  • Options table: vehicle counts around the target with the change, the estimated Rate, the price (new vehicles minus what the leaving ones sell for), the yearly cost (running costs plus purchase prices spread over the lifespan) and the cost per unit carried. The count closest to the target is marked "suggested".
  • Compare models: the line's model next to up to 5 other buyable models of the same kind that carry the cargo, each with the count it needs and its costs. The lowest cost per unit is marked "best". Click a model to see its options.
  • Apply: buys copies of the line's vehicle straight onto this line, sells the newest vehicles at once (as the game's Sell button), or switches the whole fleet to another model (replaced in place like the game's Replace window, plus extra vehicles bought or surplus ones sold). The line above the buttons says what Apply will do, and the window re-reads the line afterwards.
  • Replace window: opens the game's own Replace Vehicles window for the line's vehicles, if you prefer to pick there.
  • A line with no vehicles yet: the window suggests which model to buy and how many for the target, from the route (the straight distance between its stops) and how long your other lines of the same kind take per kilometer and at each stop (typical times when you have fewer than 3 such lines). Each row shows the vehicles needed, the estimated Rate (≈) and the costs; the lowest cost per unit is preselected. Apply buys them at the depot the game's Buy Vehicles button would use and puts them on the line. Not for train lines.

Line editor: Undo and Redo

  • Undo button (a curved-arrow icon) left of the Auto-Rename button of a single selected line: each click undoes one edit (adding, removing or moving a stop, a waypoint, a terminal, load mode, waiting times or cargo settings), most recent first.
  • Revert all: Shift+click Undo puts every stop back the way it was when you opened the line.
  • Redo button right of Undo: re-applies the edits you undid, one per click, also after a revert all. Making a new edit clears what can be redone.
  • Tooltips name the edit the next click undoes or redoes and how many changes you made since opening the line. Up to 50 steps are kept; Shift+click always reaches the start.
  • The history starts each time you open a line, and is cleared when you switch to another line or close the line manager.

Settings

  • Send to Line: target line info (On by default).
  • Send to Line: before/after estimate (On by default; on the map it needs the target line info On).
  • Line editor: Undo and Redo buttons (On by default).
  • Line list: line info on hover (On by default).
  • Send to Line list: line info panel (On by default).
  • Line editor: Line actions button (On by default).
  • Line actions: Match line rate (On by default; needs the Line actions button On).
  • Map: Shift-click a line opens the Line Manager (On by default).
  • Map: line info on hover (On by default).
  • Vehicle list: current cargo (On by default).
  • Debug: performance log (Off by default): only for tracking down slowdowns.

Notes

  • GUI only: the undo history lives in memory and nothing is stored in the savegame. Safe to add to or remove from existing saves. A duplicated or reversed line is an ordinary game line that stays as it is without the mod.
  • Only stops and the line's stop settings are undone. Name, color and vehicles are left alone. If a station from the state you go back to has been demolished, nothing is changed and a message explains why.
  • The game's own hover texts and tooltips are kept exactly as they are; if anything about a line can't be read, only the game's text is shown.
  • Match line rate's Apply only sends the game's own buy, assign, send-to-depot and replace commands, the same ones you could give by hand. Rates for the line's own model scale exactly with the number of vehicles; rates for other models are estimates from their capacity, speed and loading speed, marked with ≈.
  • Match line rate: passenger lines get no supply target (type the Rate you want). Trains, multiple units and lines that mix vehicle types get no model comparison; adding and removing copies still works. Lines with mission vehicles can't switch models.
  • Translated into all game languages.
