Additions to the line manager in one mod: Undo and Redo buttons for editing a line's stops, the target line's vehicles and numbers (and how sending changes them) while you send vehicles to another line, on the map and in the Send to Line list, the same details when you hover a line's colour dot in the line list, a Line actions button to duplicate or reverse a line, and Shift-click on the map to open the line manager on a line. Each one can be switched off on its own in the mod settings.

Replaces Line Editor Undo. Line Manager Plus includes everything Line Editor Undo does. If you use Line Editor Undo, disable it and enable Line Manager Plus instead. The game warns you when both are enabled; if you keep both anyway, only one set of undo buttons appears.

Line editor: Undo and Redo

  • Undo button (a curved-arrow icon) left of the Auto-Rename button of a single selected line: each click undoes one edit (adding, removing or moving a stop, a waypoint, a terminal, load mode, waiting times or cargo settings), most recent first.
  • Revert all: Shift+click Undo puts every stop back the way it was when you opened the line.
  • Redo button right of Undo: re-applies the edits you undid, one per click, also after a revert all. Making a new edit clears what can be redone.
  • Tooltips name the edit the next click undoes or redoes and how many changes you made since opening the line. Up to 50 steps are kept; Shift+click always reaches the start.
  • The history starts each time you open a line, and is cleared when you switch to another line or close the line manager.

Send to Line: target line info

  • Select vehicles in the line manager, click Send to Line and hover a line on the map: below the game's "Send 3 vehicles to Bus Line 1." text you see the line's vehicles, grouped by model ("3× Foo", "1× Bar", the largest groups first), or "No vehicles on this line."
  • The line's Capacity, Utilization, Frequency and Rate, worked out with the same game functions as the statistics row at the bottom of the line manager, so the numbers match.
  • Before → after estimate: the same text also shows what sending the selected vehicles would do, e.g. "Capacity: 40 → ~80", "Frequency: 7 min 19 s → ~4 min 53 s", "Rate: 66 → ~132". Frequency assumes the new vehicles are about as fast as the line's; rate grows with the added capacity. The "~" marks an estimate, and Utilization stays the current value (it depends on demand the game can't predict). Vehicles already on that line don't count; if some selected vehicles can't carry the line's cargo, a line says how many.
  • In the Send to Line list too: hover a line in the list that the Send to Line button opens, and a panel right of the list shows its name, vehicles by model and Capacity, Utilization, Frequency and Rate, with the same before → after estimate. The list itself works exactly as before.
  • Works for passenger and cargo lines of every transport type.

Line list: stats on the colour dot

  • Hover the colour dot of a line in the line manager's line list: below the game's "Open Line Window" tooltip you see the line's vehicles by model and its Capacity, Utilization, Frequency and Rate, the same details as in Send to Line.
  • Only the dot: hovering anywhere else on the row works as before, and clicking the dot still opens the line window.

Line actions: Duplicate and Reverse line

  • A Line actions button (a list icon) right of the Auto-Rename button of a single selected line opens a small menu.
  • Duplicate line makes a new line with the same stops and every stop setting (terminals, waypoints, load mode, waiting times, cargo settings), named "Bus Line 1 (copy)" ("(copy 2)" and so on if that name is taken), with a new colour picked the way the game picks one for a new line. It starts without vehicles: send some with Send to Line or buy new ones. The line manager then switches to the copy.
  • Reverse line serves the stops in the opposite order. Stop 1 stays first, waypoints follow their stretch of the route, and terminals are chosen anew for the new direction (for example the bus stop on the other side of the street). The vehicles stay on the line. With the Undo button on, one Undo takes the reverse back.
  • Greyed out, with the reason in the tooltip, for a line with fewer than 2 stops or a demolished station. If the game refuses the change, a message says so and the line stays as it was.

Map: Shift-click a line

  • Shift-click one of your lines on the map to open the line manager on it, without the line window first. A plain click still opens the line window.
  • With a line window open, Shift-click empty ground or water to open the line manager on that line (the line drawn by the window can't be clicked itself, so a click on it lands on the ground below).
  • Works on the plain map and with entity windows open. Vehicles, stations and other companies' lines open their usual window; builders and the line manager keep Shift for themselves.

Settings

  • Send to Line: target line info (On by default).
  • Send to Line: before/after estimate (On by default; on the map it needs the target line info On).
  • Line editor: Undo and Redo buttons (On by default).
  • Line list: stats on the color dot (On by default).
  • Send to Line list: line info panel (On by default).
  • Line editor: Line actions button (On by default).
  • Map: Shift-click a line opens the Line Manager (On by default).
  • Debug: performance log (Off by default): only for tracking down slowdowns.

Notes

  • GUI only: the undo history lives in memory and nothing is stored in the savegame. Safe to add to or remove from existing saves. A duplicated or reversed line is an ordinary game line that stays as it is without the mod.
  • Only stops and the line's stop settings are undone. Name, colour and vehicles are left alone. If a station from the state you go back to has been demolished, nothing is changed and a message explains why.
  • The game's own hover texts and tooltips are kept exactly as they are; if anything about a line can't be read, only the game's text is shown.
  • Translated into all game languages.
