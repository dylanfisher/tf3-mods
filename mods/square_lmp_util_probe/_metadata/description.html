DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for the planned "average Utilization" cell of Line Manager Plus and does nothing useful for players.

It only reads game data. It adds a blue marker next to the Utilization value in the Line Manager's bottom statistics row (plus a small "T2" line under the row), runs a sampler from two always-mounted GUI hosts, and writes [LMPUTILPROBE] lines to stdout.txt.
