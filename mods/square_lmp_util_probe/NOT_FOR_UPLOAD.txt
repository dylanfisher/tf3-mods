DEV ONLY - NOT FOR UPLOAD

square_lmp_util_probe is a developer tool for the planned Line Manager Plus "average Utilization over the last 12
game months" cell. Never publish it to mod.io (Mod Hub > My Mods would offer it because `make link` puts it in the
staging area).

It only reads game data and logs [LMPUTILPROBE] lines to stdout.txt. In the Line Manager's bottom statistics row it
adds a blue marker next to the Utilization value (and a small "T2 ..." line under the row) to show which hook works.
How to run it: plans/square_line_manager_plus/UTIL_PROBE.md.

When done testing: disable it in the game's mod list, or `rm` its symlink from staging_area
(make unlink removes every mod's link).
