DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer tool for Better Roundabouts and does nothing useful for players.

After you place a roundabout (Better Roundabouts or the vanilla one) it writes the build event and the lane connections of every junction node as [SQRB-LANES] lines to stdout.txt. It changes nothing unless the Write experiment setting is On.
