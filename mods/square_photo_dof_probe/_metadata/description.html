DEV ONLY - NOT FOR UPLOAD. Never publish this mod to mod.io. It is a developer test for depth of field in a photo mode and does nothing useful for players.

A top-bar button cycles the rendering environment through copies of the current base climate that switch a hand-installed probe shader between tilt-shift, depth of field, shallow depth of field and a debug view. Without that shader the button changes nothing visible.
