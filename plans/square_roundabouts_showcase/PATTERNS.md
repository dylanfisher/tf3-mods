# Showcase patterns (offline previews)

Generated offline from the mod's own layout code with real footprints: Combinations Showcase, all entries, Fill Repeat, gap 0 m, Max radius 2000 m. These are the same ASCII previews the mod writes to `stdout.txt` in a dry run (`[SQRB-SHOW] PREVIEW`). Each character shows the bounding box of whatever covers that cell, so pieces look blockier than in game, where arms interlock.

**Legend:** `R` Better Roundabouts ring, `I` Roundabout Interchange, `M` Magic Roundabout, `C` Channelized Junction, `P` Parclo, `Q` Parclo two quadrants, `D` Diamond, lowercase = mirror copy (left-hand traffic), `+` centre, `.` empty.

Regenerate: run a dry run in game, or the offline runner (see the session notes in PLAN.md).
