# Performance review: square_one_way_roads

## 2026-10-08

Verdict: **no changes, nothing worth fixing.**

### What the mod contains

- 10 `*.street_template.lua` files generated by `gen_templates.py` from the base-game templates, with the lanes flipped to one-way. Each is a single `data()` returning a static table, evaluated once at game load.
- `square_one_way_roads_presence.lua`: a static table with no side effects, `ug_require`d only by other mods.
- 10 `@2x.tga` icons (about 144 KB each) and `strings.json`.
- No `.script.tl`/`.script.lua`, no `runFn`/modifiers, no update, GUI or HUD scripts, and no event hooks.

### Changes

| Where | Before | After | Gain |
|---|---|---|---|
| none | | | |

### Examined and deliberately not changed

- Per-frame and per-event work: none exists, since the mod has no scripts.
- Load time: 10 small static Lua tables plus 10 icons, the same order of cost as the base-game street templates they copy. Well under any measurable threshold.
- Simulation: the templates keep the base lane count, widths and speeds, with only the direction flipped. Pathfinding and traffic cost match a base street of the same size.
- Generator (`gen_templates.py`): an offline tool that never ships, so it doesn't count.

### In-game check

Nothing new to check. Behaviour is unchanged.
