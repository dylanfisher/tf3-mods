# Mod Tags

The mod hub is divided in several categories. Each of the categories has some distinct tags that are used for subcategories.

Transport Fever 3 supports the following tags:

#### Map/Savegame

- `Map`
- `Savegame`

#### Climate

- `Temperate`
- `Subarctic`
- `Dry`
- `Tropical`
- `Custom`

#### Vehicle

- `Locomotive`
- `Wagon`
- `Multiple Unit`
- `Bus`
- `Truck`
- `Tram`
- `Ship`
- `Plane`
- `Helicopter`

#### Station

- `Rail Station`
- `Road Station`
- `Airport/Heliport`
- `Port`

#### Track/Road

- `Track`
- `Road`
- `Bridge`
- `Tunnel`
- `Signal`
- `Rail Crossing`
- `Road Construction`
- `Track Construction`

#### Building

- `Industry`
- `Town Building`
- `Warehouse`
- `Landmark`
- `Depot`
- `Maintenance Building`

#### Asset

- `Vegetation`
- `Rock`
- `Other Asset`

#### Misc

- `Script Mod`
- `Car`
- `Resident`
- `Animal`
- `Sound`
- `Shader`
- `Campaign`
- `Localization`
- `Misc`

> **Tip:**
>
> To keep the categories clean, it is recommended to choose at most up to three major tags that support what users would use to find a mod. A combined industry with embedded station would primarily count as `Industry`. A combined airport with underground train station would likely equally fit in both `Rail Station` and `Airport/Heliport`. A script mod that adjusts metadata of locomotives is still a `Script Mod` and not a `Locomotive`.
