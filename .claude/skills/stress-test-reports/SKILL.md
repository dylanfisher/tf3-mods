# Game-log reports

- `make perf [LOG=path] [ARGS='--mod X --last --skip 1']`: per-mod report of the `[SQPERF]` lines in the latest `stdout.txt` (`--last`: the most recent load that has SQPERF lines). Enable the DEV mod `mods/square_sqperf_all` (never upload) to turn every SQPERF mod's debug log on at once.
- `make audit [LOG=path] [ARGS='--last --src auto|tool|pick --top 5']`: Smart Lanes junction audit report from the latest `stdout.txt`: the `[SQRL] AUDIT` lines grouped by finding (squeeze, shared, across, ramp_ramp, u_turn, unfed, dead, bypassed_turn, weave, lights), the worst junctions per finding with case / shape / detail, `AUDIT_SUMMARY` totals and skip reasons. Run it after the Stress Test's Junction test and Crossing test. See `plans/square_smart_lanes/TESTING.md` "X".
- `make flow [LOG=path] [ARGS='--last --warmup 180 --worse-pct 10 --min-samples 5 --ignore-reason entry --retime-settle 60 --auto-settle 2700']`: traffic flow A/B report from the Stress Test traffic log (`[SQST] FLOW_*` lines): the Showcase twins compared pairwise (`sl` / `sl_phases` / `sl_classic` / ... vs `game`, same `pair=`) and pooled per kind / type (speed, % standing, stand time, queue, thru/min; sign test across pairs), pairs with `match=no` (unless `--ignore-reason` lists all its reasons) or a missing twin excluded, zones worse than game, FLOW_ALL trend, buses, towns; `[SQRL] TOGGLE` blocks as a fallback. Light plans A/B (Lights showcase > Build light plans A/B: twins game / sl_phases (axis) / sl_auto (axis + Smart Lanes' automatic re-timing; sl_classic in the earlier `variant=light_plans_classic` build), balanced and unbalanced sets (zone lines' `demand=`)): a section per shape and demand game vs axis vs auto (thru/min, queue per arm, standing, km/h) with a verdict line each. Auto timing (`[SQRL] AUTORETIME op=write sent=1`, twin by `zid=`): a set whose auto twin wrote is split like a Re-time: before its first write in the tables, from its settled-from time (first write + `--auto-settle`, default 2700 game s since Smart Lanes step B v4) as set `<pair>+as` (mode `sl_auto+as`); the light plans section compares every plan in that settled window; an "Auto timing: as built / settled" section per set. Whole-map auto re-time (Stress Test "Auto re-time > All lit junctions", `AUTORETIME op=enroll_all phase=done`): enrolled zones and FLOW_ALL before the request vs from `--auto-settle` after it. FLOW_TOWNS `pop=`: town populations per class (busy / small / tiny / other). Smart Lanes Re-time writes (`[SQRL] RETIME op=write`, twin by the node's `zid=`) split their set: before in the tables, after as set `<pair>+rt` (mode `<ab>+rt`) and a Re-time before / after section relative to the game twin. Ring lane use (bench Sheet 5: zone lines' `mix=even|straight|adjacent`, `[SQST] RINGMIX` / `RINGLANE` cumulative per sampler run, the recorded window = last line minus the first after the warm-up cut): a "Ring lane use" section per ring and mix (thru/min, km/h, standing, queue per arm, lane use outer lane first clustered from RINGLANE distances, measured turning mix 1st / 2nd / 3rd / U-turn), a RINGMIX table per twin, a gridlock check per twin (bench Sheet 6: the last 3 two-minute windows at >= 80 % standing with thru <= 25 % of the set's best: "GRIDLOCK from game min n") and a verdict line per ring and mix (each mode vs game and vs sl_rturbo; a note when the measured mix does not bear out its label); `make bench` adds the same section for its run. Contract: `plans/square_stress_test/FLOW.md` ("Light plans and Re-time in the report", "Auto timing in the report", "RINGMIX / RINGLANE", "Ring lane use in the report"); The bench's city run (Stress Test "City lights", `[SQST] CITY` / `CITY_ENROLL`, zones ab=city_auto|city_control): section "Auto lights at scale": Smart Lanes' frame cost from `[SQPERF] mod=square_smart_lanes ctx=bg` (needs its Debug: performance log On), the person-list spikes of `AUTORETIME op=snapshot src=scan` flagged apart, writes per game minute, junctions written, first fits, every city before the enroll vs from --auto-settle after it, auto minus control, and the pass criteria (no frame > 5 ms, mean < 1.5 ms/frame at 4x, no city > 10 % slower). Contract: FLOW.md "Auto lights at scale in the report", "Gridlock per twin". How to run it: TESTING.md 6Z (light plans with the auto twin), 6Z2 (whole-map button), 6Z3 (city lights at scale), 6Y2 (bench sheet 5) and 6Y3 (bench sheet 6).
- `make bench [LOG=session] [ARGS='--record --warmup 180']`: Stress Test bench report for the last bench sheet run (default `LOG=last-bench`): per test and comparison Δ km/h, wins / losses, sign / Holm / Wilcoxon p, standing, throughput, a per-twin mode check from Smart Lanes' `zid=` lines, sampler health; writes a draft RESULTS.md entry to `.cache/bench/<session>.md`. `--record` (only after `BENCH_DONE ok=yes`) appends the pairs to `plans/square_smart_lanes/bench_ledger.json` and the entry to `plans/square_smart_lanes/RESULTS.md`. Design: `plans/square_stress_test/BENCH.md`.

`LOG=` takes a session name or prefix, `last`, `last-crash`, `last-<tag or Stress Test action>`, a seed or `live` (see `make logs` in CLAUDE.md).
